==================================================
F. REQUIRED SEARCH BEHAVIOR
==================================================

Search engines are discovery tools only.

For every discovery:
1. identify original agency/buyer;
2. locate primary official source;
3. locate related procurement package documents;
4. acquire official evidence;
5. preserve source URL;
6. checksum;
7. Supabase Storage;
8. normal extraction;
9. human verification queue.

When a seed gives only an agenda approval:
hunt the actual contract.

When a seed gives only a bid tab:
hunt the solicitation and final award.

When a seed gives only a contract:
hunt the solicitation, bid tab, award, amendments and renewal.

The goal is PROCUREMENT PACKAGE RECONSTRUCTION.

==================================================
G. SOURCE-SPECIFIC RULES
==================================================

SAM.gov:
- Public Opportunities API requires a public API key.
- Use pagination and archived/active windows.
- Acquire public attachments where available.

USAspending:
- Public API endpoints currently require no authorization.
- Use recipient autocomplete, spending_by_award, NAICS/PSC filters.
- Preserve award IDs and retrieval metadata.

Texas ESBD:
- Public solicitation search does not require sign-in.
- Search agency, status, class/item, keyword, solicitation ID, date range.
- CSV export exists.
- Monitor Addendum Posted / updates.

VPTS:
- Prefer authoritative vendor ID or PO when known.
- Search also supports vendor name.
- Recent published records only; older records may require open records.
- Mark unavailable older items OPEN_RECORDS_REQUIRED / MANUAL_IMPORT.

TOPS:
- Public business-license search is available.
- Current TOPS result controls current license/insurance state.
- Historical disciplinary reports remain historical.

Texas Open Data:
- Prefer API/OData/Socrata access.
- Preserve dataset ID, filter/query and retrieved_at.
