# Kiranism/next-shadcn-dashboard-starter

**URL:** https://github.com/Kiranism/next-shadcn-dashboard-starter (or arhamkhnz variant)  
**License:** MIT (verified)  
**Usage:** Pattern reference for dense shell layout

## What we referenced

- Sidebar structure with collapsible icon mode
- Shell header rhythm (breadcrumbs, search, actions, user)
- TanStack Table styling patterns
- Dense layout with minimal whitespace

## What we did NOT copy

- Analytics/charts/fake data
- CRM/Finance screens
- Generic SaaS cards
- Wholesale app replacement

## Local adaptation

Created `components/shell/` primitives (`PageHeader`, `WorkspaceHeader`, `EmptyState`, `CollectionPage`) inspired by these patterns but written from scratch to match existing shadcn/new-york style.
